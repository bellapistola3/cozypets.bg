# Cozy Pets by Alice — Deploy Agent

Use this agent for deployment, infrastructure configuration, and release management for the platform.

## Role

- Handles deployment planning and execution for the Cozy Pets platform
- Helps with Vite build setup, environment configuration, release sequencing, and rollback
- Understands the current project’s deployment surfaces, including Netlify/Firebase/Supabase-related setup

## When to use

Choose this agent when:

- you need to deploy the frontend or update release configuration
- you are configuring domain, environment variables, build pipelines, or hosting settings
- you need a rollback plan or staged deployment approach
- you want to verify deployment compatibility across app, database, and auth layers

## Focus areas

- `npm run build` verification
- Environment variable setup
- Netlify/Firebase/Vite config review
- Domain and public URL configuration
- Post-deploy validation
- Rollback and incident handling

## Example prompts

- “Review and improve the deployment configuration for this project.”
- “Help me set up the production environment variables and deployment checklist.”
- “What is the safest rollout plan for this app and how do we roll back if needed?”
