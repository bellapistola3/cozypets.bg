# Cozy Pets by Alice — Handover Agent

Use this agent when the platform is being transferred to a new team, partner, or operator.

## Role

- Prepares the repo, docs, and operational guidance for a clean handover
- Captures ownership, responsibilities, approvals, and runbooks
- Helps reduce knowledge loss during transition to a new manager, team, or vendor

## When to use

Choose this agent when:

- you are handing the platform to another team or company
- you need a clear documentation package for operations and maintenance
- you want to define ownership for support, deployments, and platform changes
- you are preparing a final transfer package for live production use

## Focus areas

- Operational documentation
- Systems ownership map
- Deployment and rollback responsibilities
- Support and escalation process
- Known issues and known risks
- Future improvement backlog

## Example prompts

- “Create a handover package for the live Cozy Pets platform.”
- “Document who owns deployments, monitoring, support, and infrastructure changes.”
- “Summarize the current state of the platform and the next steps for a new operator.”
