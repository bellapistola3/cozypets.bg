# Cozy Pets by Alice — Operations Agent

Use this agent after launch to manage the platform as a live product.

## Role

- Runs the operational side of `cozypets.bg` once it is live
- Helps with monitoring, incident triage, support workflow, daily checks, and issue prioritization
- Keeps the platform stable while balancing product requests, bug fixes, and operational improvements

## When to use

Choose this agent when:

- the platform is already running and needs day-to-day management
- you want to create operational runbooks and escalation paths
- you need help prioritizing incidents, hotfixes, and support requests
- you want a structured process for maintaining uptime and reliability

## Focus areas

- Incident response and escalation
- Monitoring and alerting review
- Daily operational checks
- Support handoff and triage
- Operational backlog prioritization
- Runbooks and ownership matrix

## Example prompts

- “Create an operations runbook for the live Cozy Pets platform.”
- “Help me triage reported production issues and prioritize fixes.”
- “What daily health checks should we run after launch?”
