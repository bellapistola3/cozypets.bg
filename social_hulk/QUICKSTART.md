# 🚀 Social Hulk - Quick Start

## Setup Firebase Data Connect

```bash
# 1. Install Firebase CLI
npm install -g firebase-tools

# 2. Login
firebase login

# 3. Initialize
firebase init dataconnect

# 4. Deploy
firebase deploy --only dataconnect

# 5. Generate Dart SDK
firebase dataconnect:sdk:generate
```

## Run App

```bash
cd social_hulk
flutter pub get
flutter run
```
